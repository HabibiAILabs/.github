## Projects

- **[habibi](https://github.com/HabibiAssistant/habibi)** — the Rust runtime, event reactor, model transport, extension host, and local management UI.
- **[extensions](https://github.com/HabibiAssistant/extensions)** — official, versioned extensions installable from Git or local checkouts.

Habibi keeps domain history durable, treats execution details as searchable logs, and lets extensions add web interfaces, tools, event projections, and private KV state without depending on a hosted service.
